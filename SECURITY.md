# Security reporting

Do not post credentials or vulnerability details in a public issue.
Report suspected vulnerabilities privately to david@lemarier.ca with the affected
revision, reproduction, impact, and any suggested mitigation. Never include live
secrets; describe their location and exposure instead.

Kitchen is under development and has no supported production release yet.
Security fixes target the current development branch. Publication, live job
activation, and access to credentials require their own explicit authorization.
