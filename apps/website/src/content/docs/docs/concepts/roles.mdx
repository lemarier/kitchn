Each role is a contract: a responsibility, the evidence it must deliver, and a
boundary it may not cross. Roles are separate from domain specialties and from
house policy, which are loaded from the task's pinned guidance.

Roles open when there is work for them. Installing a role starts no worker or
schedule and grants no authority.

This page is generated from the role cards in the repository's `roles/`
directory, the same files kitchn embeds and verifies.
